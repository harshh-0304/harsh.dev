# Portfolio Development Rules

This is a premium personal portfolio.

Goal:
Create an award-worthy developer portfolio that feels like Linear, Vercel, Stripe, Apple and Raycast.

DO NOT redesign sections unnecessarily.

Instead:
- Improve polish
- Improve UX
- Improve motion
- Improve hierarchy
- Improve accessibility
- Improve responsiveness
- Improve performance

Tech Stack
- Next.js
- React
- TailwindCSS
- Framer Motion
- TypeScript

Animation Philosophy

Animations should:
- feel natural
- never block interaction
- use easing
- avoid excessive duration
- trigger once where appropriate
- respect prefers-reduced-motion

Never:
- overuse blur
- overuse glassmorphism
- overuse gradients
- create distracting animations
- animate everything

Always maintain:
- premium SaaS aesthetic
- dark modern theme
- clean spacing
- accessibility
- performance

Code Rules

- reusable components
- no duplicate code
- clean architecture
- lazy load heavy components
- avoid unnecessary rerenders
- use motion variants
- avoid inline styles
- keep animations configurable

Performance

Target:
95+ Lighthouse

Avoid:
-heavy JS
-large images
-layout shift
-expensive scroll listeners

Always optimize.
